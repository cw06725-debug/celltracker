# CellTracker v0.4.0

## Added
- Live Map entry from the main screen.
- Live GPS position while recording.
- Recording track refreshes from the same CSV used for export/history replay.
- RAT-colored track segments.
- Live camera follows the current GPS position during recording.
- Current RAT and RSRP shown above the live map.
- Existing v0.3.5 history map fixes retained.

## Test focus
1. Start a recording, open Map, and walk/drive 50-100 m.
2. Confirm the current location follows movement and the track grows.
3. Confirm RAT changes create differently colored track segments.
4. Stop recording and confirm the latest track remains visible.
